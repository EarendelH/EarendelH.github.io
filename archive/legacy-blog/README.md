# Legacy Blog Archive

This directory preserves the previous blog while keeping it out of the public Jekyll site. It contains 19 post sources, 207 referenced media files, and the former blog, category, and tag pages. `_config.yml` excludes the entire `archive/` directory.

To restore the blog later, move `_posts/`, `images/blog/`, and the files under `_pages/` back to their original repository locations. Then re-enable the Blog navigation item, homepage links, and Atom feed before rebuilding the site.
